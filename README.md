# Drone Status Struct

Small C project that describes a drone using a `struct` and runs basic safety checks.

## What It Does

- Stores drone data in one structure.
- Uses an enum for flight mode.
- Uses bit flags for errors.
- Runs battery, temperature, and speed checks.
- Prints a readable status report.

## What I Practice

- `struct`
- `enum`
- Functions with structures
- Bit flags
- Data grouping
- Embedded-style status models

## Build And Run

```sh
make
./drone-status-struct
```
